⚠️ System Requirements & Setup Guide

Read this guide to prepare your system for the ultimate experience!

The Sacred Tech features 22 educational chapters. Depending on your system tools, the game operates across three feature tiers:

Tier 1: Core JRPG Game (Required)
• What it does: Access all 22 chapters, overworld maps, combat, editor, verification system, and saves.
• Requirements: Python 3.10+ (with pip) & a modern web browser.
• Download Status: Already running! All packages (FastAPI, uvicorn, numpy, etc.) are installed automatically in your local environment.
Tier 2: Arch Linux Sandbox (Optional)
• What it does: Turns the Alt+5 Terminal into a real sandboxed Arch Linux environment where your chapter code compiles safely inside an isolated container.
• Requirements (Must Download Externally):
    - Windows/macOS: Download and run Docker Desktop.
    - Linux: Install docker (e.g., sudo apt install docker.io or sudo pacman -S docker). Make sure to add yourself to the docker group: sudo usermod -aG docker $USER, then restart your shell.
• How to build: Run python setup/install_all.py (or select it on install) to build the container automatically.
Tier 3: TempleOS Altar VM (Optional)
• What it does: Drives a real TempleOS virtual machine inside the Alt+7 tab for the final Chapter 21 Altar puzzles.
• Requirements (Must Download Externally): QEMU emulator.
    - Windows: Run winget install SoftwareDesignLabs.QEMU
    - macOS: Run brew install qemu
    - Linux: Run sudo apt install qemu-system-x86 qemu-utils
• How to build: Run the installer setup/install_all.py or script setup/build_templeos_img.sh to build the VM image.

⚠️ Note: If Docker or QEMU are missing, the game falls back gracefully to host-level execution and simulated altars. You do not need to install them to play!

How to download & install everything else automatically:

  1. Make sure Python 3.10+ is installed on your machine.
  2. Run the unified installer in your terminal:
    python setup/install_all.py
  3. Start the game server:
    Windows: .\scripts\run_dev.ps1
    macOS/Linux: ./scripts/run_dev.sh
